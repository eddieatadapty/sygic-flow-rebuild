# Sygic Growth Audit

**Live → https://eddieatadapty.github.io/sygic-flow-rebuild/**

Five ideas to turn more Sygic users into subscribers, each built into a clickable version of Sygic's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask how they drive, then set Sygic up for it | +10–20% CR to purchase |
| 02 | Make the map download the first win | +5–15% CR to purchase |
| 03 | Show what Free can’t do | +10–20% CR to purchase |
| 04 | Lead with the yearly plan at $1.67 a month | +10–15% ARPU, more yearly plans |
| 05 | Catch the drivers who close the paywall | +10–15% ARPU, from people who say no |

Every price, rating and feature comes from Sygic's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Sygic. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
